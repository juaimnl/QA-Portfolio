# QA-Portfolio
A collection of QA practice projects demonstrating manual testing, bug reporting, JIRA, and Postman API testing.

This repository contains my hands-on practice in Manual Testing, where I apply QA principles by creating test cases, documenting bugs, and performing different testing techniques using demo web applications.

The goal of this portfolio is to demonstrate my understanding of software testing fundamentals and continuously improve my QA skills through practical projects.
